# React Note App 📝

A simple and responsive **Note Taking App** built with React.  
Easily create, view, and delete notes in a clean interface.  

---
## 🌐 Live Demo

Check out the live app here:  
[https://noteapp-04.vercel.app/](https://noteapp-04.vercel.app/)

---
## ⚡ Features

- Add notes with **title** and **details**.
- Delete individual notes.
- Responsive design – works on desktop and mobile.
- Clean and simple interface for easy note management.
